# End-to-End ETL Pipeline

## Project Overview
Extract data from API, transform it
using Pandas and load it into PostgreSQL.

## Technologies Used
- Python
- Pandas
- PostgreSQL
- SQLAlchemy
- Requests

## Project Architecture
Extract → Transform → Load

## Project Features
- API data extraction
- Data cleaning
- Duplicate removal
- PostgreSQL integration

## How to Run
1. Install requirements
2. Configure .env
3. Run python -m src.main

## Output
Cleaned user data stored in PostgreSQL.
